# 🚖 Uber Trip Analysis & Demand Prediction

## 📌 Project Overview
This project focuses on analyzing aggregated daily Uber trip statistics in New York City (January and February 2015) to uncover hidden demand patterns. Furthermore, it builds an automated machine learning pipeline that trains and compares multiple regression models to forecast the future number of Uber trips based on fleet size, date, and dispatch base. 

As a Data Analyst or Data Scientist, predicting ride demand is crucial for optimizing fleet deployment, minimizing passenger wait times, and maximizing revenue.

## 📊 Dataset
The project uses the **TLC FOIL Response** dataset for Uber pickups.
* **File:** `Uber-Jan-Feb-FOIL.csv`
* **Features:**
  * `dispatching_base_number`: The TLC base company code.
  * `date`: The date of the recorded trips.
  * `active_vehicles`: The number of active Uber vehicles on that date.
  * `trips`: The total number of completed trips (Target Variable).

## 🛠️ Technologies & Libraries Used
* **Programming Language:** Python
* **Data Manipulation:** `pandas`, `numpy`
* **Data Visualization:** `matplotlib`, `seaborn`
* **Machine Learning:** `scikit-learn`, `xgboost`

## 🚀 Project Workflow

### 1. Data Preprocessing
* Converted raw date strings into standard Python `datetime` objects.
* Mapped alphanumeric TLC dispatch base codes (e.g., *B02512*) to their actual company names (e.g., *Unter*, *Grun*) to make the analysis interpreitable for business stakeholders.

### 2. Exploratory Data Analysis (EDA)
Conducted visual analysis to understand ride patterns:
* **Demand by Day of Week:** Identified which days of the week experience peak ride volume.
* **Demand by Dispatch Base:** Analyzed which specific Uber bases handle the highest volume of trips.
* **Vehicles vs. Trips:** Explored the correlation between the number of active vehicles on the road and the total number of completed rides.

### 3. Feature Engineering
* **Temporal Features:** Extracted `Day` and `Month` from the datetime data to capture seasonal and daily trends.
* **Categorical Encoding:** Applied One-Hot Encoding (`pd.get_dummies`) to the categorical `Base_Name` feature so it could be processed by the machine learning algorithms.

### 4. Model Training & Automated Selection
The data was split into training (70%) and testing (30%) sets. To ensure we deploy the most accurate predictive algorithm, the pipeline trains multiple models simultaneously:
* **Decision Tree Regressor**
* **Random Forest Regressor**
* **Gradient Boosting Regressor**
* **XGBoost Regressor**

**Evaluation Metrics:** The models are evaluated based on **Mean Absolute Error (MAE)** and **R² Score**. The script automatically identifies and selects the model with the lowest MAE as the final production model.

### 5. Forecasting & Business Scenarios
* **Visualization:** Plotted the actual trip data from the test set against the predictions generated by the Best Model to visually verify accuracy.
* **Scenario Prediction:** Built a custom forecasting block where business inputs (like active vehicles, day of the week, and month) can be passed into the final model to predict the expected number of trips for an upcoming day.
